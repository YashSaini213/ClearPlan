## 📌 About The Project

**ClearPlan** is a full-stack task management web application designed to help users organize their daily work and stay productive.

Users can create tasks, assign priorities and deadlines, update task information, track their progress, and delete completed or unnecessary tasks.

The application is built using the **MERN stack — MongoDB, Express.js, React.js, and Node.js**.

---

## ✨ Features

### 📋 Task Management

- ➕ Create new tasks
- ✏️ Update existing tasks
- 🗑️ Delete tasks
- 📅 Set task deadlines
- 🔥 Assign task priorities
- 📊 Track daily tasks
- ✅ Manage task status
- 📱 Responsive interface

### 👤 User Experience

- Clean and intuitive interface
- Easy task organization
- Priority-based task management

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YashSaini213/ClearPlan.git
```

### 2. Navigate to the project

```bash
cd ClearPlan
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file and add the required configuration:

```env
MONGODB_URI=your_mongodb_connection_string
```

Add any other environment variables required by your backend.

> ⚠️ Never commit your `.env` file to GitHub.

Add this to `.gitignore`:

```gitignore
node_modules/
.env
.env.*
!.env.example
dist/
```

---

## ▶️ Run Locally

Start the development server:

```bash
npm run dev
```

Open the URL provided by Vite in your browser.
